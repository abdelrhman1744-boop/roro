# 🌟 مشروع رورو

صفحة فخمة بتصميم نيون متوهّج وتأثيرات ضوء وموسيقى خلفية أنيقة.  
تم إنشاؤها بواسطة عبد الرحمن 👑 لإظهار الإبداع في تصميم واجهات الويب.

## 💡 المميزات
- تأثيرات نيون متحركة.
- موسيقى خلفية هادئة.
- تصميم متجاوب مع جميع الأجهزة.

## 🚀 طريقة العرض
افتح ملف `roro.html` وشغّله في المتصفح، واستمتع بالتجربة البصرية والصوتية.

## 🧠 فكرة المشروع
دمج الجمال البصري مع الصوتي في صفحة واحدة، لتكون تجربة فريدة ومريحة للعين والأذن.
